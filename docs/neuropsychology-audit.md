# Neuropsychology Copy Audit

## Objectif

Utiliser la psychologie de lecture pour réduire l’effort inutile et l’incertitude, jamais pour forcer une décision.

## Principes appliqués

### Processing fluency
Phrases courtes, vocabulaire concret, structure prévisible.

### Cognitive load
Une idée dominante par bloc. Les détails techniques sont progressivement révélés.

### Salience
Hiérarchie nette : identité → valeur → preuve → expertise → réalisations → action.

### Progressive disclosure
Le visiteur comprend d’abord le problème et la valeur ; les détails d’architecture arrivent ensuite.

### Specificity
Préférer un contexte, une décision ou une preuve à un adjectif comme « révolutionnaire ».

### Uncertainty reduction
Chaque CTA important explique ce qui se passe ensuite.

### Choice architecture
Une action primaire par page critique ; les actions secondaires ne doivent pas rivaliser avec elle.

### Commitment gradient
Accueil → réalisation → contexte → contact. La demande de contact arrive après suffisamment d’information.

### Social proof
Uniquement authentique, contextualisée et vérifiable.

## Interdits

Aucune fausse rareté, compte à rebours artificiel, culpabilisation, peur fabriquée, option cachée ou pression artificielle.

## Contrôle

Pour chaque page critique :

- message principal identifiable ;
- preuve proche ;
- CTA cohérent ;
- informations nécessaires disponibles avant décision ;
- aucune technique de persuasion trompeuse.
